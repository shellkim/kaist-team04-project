# Feature Spec — Skin Scheduler

Author: Eunhye Hyun (현은혜)
Date: 2026-10-28
Status: decided

기능은 스케줄러다. P0 화면은 오늘 체크리스트다.

한 줄: 받은 시술을 고르면, 오늘 할 일과 피할 일이 그 시술과 예시 날씨에 맞춰 나온다. 숫자는 깨는 만큼 올라간다.

---

## Who it is for, and the moment the problem shows up

**Who:** 시술에 돈을 쓰지만, 매일 뭘 해야 하는지 다시 생각하고 싶지 않은 20–40 워킹우먼.

**Moment:** 아침, 또는 시술 다음 날. 병원 안내는 이미 치웠고, 자외선·보습·마찰을 오늘 다시 검색하기 직전에 앱을 연다.

받을지 미룰지를 적는 사람은 이 화면의 주 사용자가 아니다.

면책(Footer, 작은 글씨): 이 앱은 개인용 케어 가이드이며 의료 진단이나 치료를 대신하지 않습니다. 병원 안내가 있는 경우 항상 병원 지침을 최우선으로 따라주세요.

## Core logic — 오늘 목록을 고르는 방법

화면에 `카테고리`, `이름`, `저장`, `오늘 참고` 같은 관리자 말은 쓰지 않는다.

```
앱을 연다
  → 시술이 없는가?
      yes → 시술 고르기 화면. 칩 + 찾기 + 날짜
      no  → N = 시술일부터의 날
            N ≤ 6 → 그 그룹 초반/후반 할 일 + 피할 일
            N ≥ 7 → 유지 할 일
```

- 시술일 = D+0. 같은 날 여러 시술을 고를 수 있다. 저장하면 그 선택이 오늘 패키지가 된다.
- 복합 선택 시 할 일은 강한 그룹이 아침·저녁을 차지한다. 순서: 강한 레이저 → 주사 → 리프팅 → 보톡스/필러 → 토닝. 피할 일은 합친다.
- 오늘 = 브라우저 로컬 날짜.
- 예보 mock 고정 (`예시`): 자외선 높음 7(붉은 틴팅) · 습도 낮음 35% · 기온 18°C. 액션 `오늘은 미스트를 가지고 나가서, 한번 씩 뿌려 주세요.`

**해야 할 일 (DO):** 아침·저녁은 종 이모지만. 누르면 mock 알림 시각을 만든다. 점심은 12:30 고정. 저녁 할 일이 없으면 그 칸은 비운다(후반·유지). 문구는 고칠 수 없다. 제목에 `(완료/전체)`.

**피할 일 (DON'T):** 회복 중(N ≤ 6)만. **체크 불가.** 할 일 카드 **안쪽 상단** 배지. 제목 `오늘 이것만은 피하기`. All Clear에 넣지 않는다.

## What the user can do, step by step

### 시술이 없을 때

1. 헤더: `오늘 어떤 피부 관리를 받으셨나요?`
2. 서브: `시술명만 알려주시면 일자별 맞춤 케어 플랜을 짜드릴게요.`
3. 인기 시술은 칩. 찾기로 걸러진다. 그룹은 다섯이고 겹치지 않는다.
4. 칩을 하나 이상 고르고 날짜를 고른 뒤 `맞춤 케어 시작하기`. 같은 날 복합 시술은 칩을 여러 개 누른다.

다섯 그룹 (P0, MECE):

1. 스킨부스터·주사 — 리쥬란, 쥬베룩, 엑소좀, 물광주사
2. 토닝·색소 레이저 — 피코토닝, 헬리오스, IPL
3. 강한 레이저·박피 — 프락셀, CO2, 점 빼기
4. 보톡스·필러 — 턱보톡스, 윤곽주사, 필러
5. 에너지 리프팅 — 울쎄라, 슈링크, 인모드

그룹 이름은 칩 위에 작은 구분일 뿐, 두 번 고르는 드롭다운이 아니다. 화면 말: `받으신 시술`. `카테고리` / `이름` / `저장` 금지.

### 오늘 홈

1. 헤더: `10/28(수) · 리쥬란 D+1`. 그 아래 따뜻한 한 줄. 예: `오늘도 엠보싱 자극 없이 잘 케어해 봐요!` (주사 초반). 다른 그룹은 `오늘도 피부 리듬에 맞춰 천천히 가 봐요.`
2. `오늘의 피부 일기` (`예시`): 자외선 7 · 습도 35% · 기온 18°C. 액션 `오늘은 미스트를 가지고 나가서, 한번 씩 뿌려 주세요.`
3. `📋 오늘의 맞춤 케어`: 아침 세안 → 점심 선크림 → 저녁 보습(초반만). 아침·저녁은 🔔로 알림을 만들고, 점심은 12:30. `🚫 오늘 이것만은 피하기`는 같은 카드 위.
4. 박스를 깨면 선이 그어지고 숫자가 `1/3`으로 오른다. 다 깨면 `오늘 케어 All Clear`와 토스트 `오늘도 자극 없이 완벽하게 케어하셨어요!`
5. 병원 안내: `💬 피부 상태가 평소와 다르게 불안하신가요? 시술받으신 병원에 문의하시면 가장 정확한 안심을 얻으실 수 있어요.`
6. 우측 하단 확장 버튼: `+ 다른 시술 추가` → 같은 고르기 화면. 여러 칩을 고르면 그 패키지로 덮어쓴다.
7. Footer 면책. 날짜가 바뀌면 체크만 리셋

## P0 템플릿 (이 문자열이 정답)

피부 일기 (`예시`): 자외선 7 · 습도 35% · 기온 18°C → `오늘은 미스트를 가지고 나가서, 한번 씩 뿌려 주세요.`

공통 점심: `무기자차 선크림을 2시간마다 덧바르세요.` 시각 12:30.

할 일 문장은 모두 `~하세요`로 맞춘다. D+N과 시술 이름은 헤더에만.

**스킨부스터·주사** 초반: 아침 `약산성 거품으로 세안하세요. 엠보 부위는 문지르지 마세요.` / 점심 선크림 / 저녁 `수분 크림을 얇게 2~3번 겹쳐 바르세요.` · 피하기 `음주 (열감·붓기)` `사우나 (열감)` · 헤더 한 줄 `오늘도 엠보싱 자극 없이 잘 케어해 봐요!`

**스킨부스터·주사** 후반: 아침 `약산성 거품으로 가볍게 세안하세요.` / 점심 선크림 / 저녁 없음 · 피하기 `음주`

**토닝·색소 레이저** 초반: 아침 `미온수로 짧게 세안하세요. 붉은 기는 문지르지 마세요.` / 점심 선크림 / 저녁 `보습 크림을 조금 더 두껍게 바르세요.` · 피하기 `사우나` `강한 마찰`

**토닝·색소 레이저** 후반: 아침 `미온수로 세안하고, 당기면 보습하세요.` / 점심 선크림 / 저녁 없음 · 피하기 `사우나`

**강한 레이저·박피** 초반: 아침 `세안은 손끝으로만 하세요. 문지르지 마세요.` / 점심 선크림 / 저녁 `보습을 자주, 얇게 올려 주세요.` · 피하기 `사우나` `운동으로 땀 흘리기` `음주`

**강한 레이저·박피** 후반: 아침 `미온수로 짧게 세안하세요.` / 점심 선크림 / 저녁 없음 · 피하기 `사우나`

**보톡스·필러** 초반: 아침 `세안은 살살 하세요. 시술 부위는 누르지 마세요.` / 점심 선크림 / 저녁 `보습 크림을 조금 더 두껍게 바르세요.` · 피하기 `시술 당일 눕기·숙이기` `사우나` `음주`

**보톡스·필러** 후반: 아침 `평소처럼 세안하되, 세게 문지르지 마세요.` / 점심 선크림 / 저녁 없음 · 피하기 `사우나`

**에너지 리프팅** 초반: 아침 `열감이 있으면 차갑게 식히고, 미온수로 세안하세요.` / 점심 선크림 / 저녁 `보습 크림을 조금 더 두껍게 바르세요.` · 피하기 `사우나` `강한 마사지`

**에너지 리프팅** 후반: 아침 `미온수로 세안하고 보습하세요.` / 점심 선크림 / 저녁 없음 · 피하기 `사우나`

N≥7: 아침 `약산성 거품으로 세안하세요.` / 점심 선크림 / 저녁 없음 · 피하기 없음 · 헤더 한 줄 `오늘도 피부 리듬에 맞춰 천천히 가 봐요.`

다른 그룹의 기본 헤더 한 줄도 같다. 주사 초반만 엠보싱 문장.

## How you will check it works: hand tests

**Test 1 — 고르기 화면**

1. 시술 없이 연다.
2. `오늘 어떤 피부 관리를 받으셨나요?`와 칩, `맞춤 케어 시작하기`가 있다.
3. `카테고리`, `이름`, `저장` 글자가 없다. 오늘 할 일 목록이 없다.

**Test 2 — 리쥬란 칩 → 홈**

1. `리쥬란` 칩, 어제 날짜, `맞춤 케어 시작하기`.
2. 헤더 `리쥬란 D+1`, `엠보싱`, 미스트 액션 한 줄, `📋 오늘의 맞춤 케어 (0/3 완료)`.
3. 아침 엠보 세안(🔔 알림 만들기), 점심 12:30 선크림, 저녁 겹쳐 바르기(🔔). `🚫 오늘 이것만은 피하기`에 음주. 체크박스 아님.
4. 박스 하나 깨면 `(1/3 완료)`.
5. `다른 시술 추가` → `피코토닝` → 붉은 기 문구, 음주 배지 없음.

**Test 3 — All Clear**

1. 3개 모두 깨면 All Clear와 축하 토스트. 피할 일은 안 깨도 된다.
2. 병원 안내에 `불안하신가요`가 있다.

## Rules behind the tests (P0)

- 시술은 칩으로만. 그룹은 자동.
- DON'T는 체크 불가. All Clear는 DO만.
- `카테고리` / `이름` / `저장` / `오늘 참고`를 화면에 쓰지 않는다.
