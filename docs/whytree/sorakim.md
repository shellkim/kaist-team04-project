## 피부 미용에 대한 주체적인 의사결정

### A. 시술 정보의 불확실성 감소

- 최신 시술 트렌드 파악
  - 커뮤니티 기반 시술 트렌드 분석
- 시술별 특징과 실제 경험 이해
  - AI 기반 커뮤니티 후기 요약
  - 시술별 비교 가이드 제공 [대안]

### B. 개인 시술 경험의 활용

- 과거 시술 경험의 체계적인 축적
  - AI 대화 기반 시술 이력 기록
  - 진료 내역·영수증 기반 자동 기록 [대안]
- 시술 후 실제 경험 파악
  - 통증·효과·만족도 기록
  - 시술 후 경과 기록 리마인더 [대안]

### C. 개인에게 중요한 선택 기준 반영

- 개인의 선호도와 제약 조건 파악
  - AI 대화를 통한 선호도 분석
- 개인 경험과 외부 정보 연결
  - 개인 이력과 커뮤니티 정보 기반 시술 비교
  - 의료진 상담용 질문 목록 생성 [대안]
