표기 규칙

- `[씨앗]` 먼저 생각난 일 (주황 상자)
- `[why]` 목적 (실선 상자)
- `[how]` 아직 하지 않지만 새로 찾은 일 (점선 상자)
- 화살표는 how → why, 아래에서 위로 향한다. `(점선)`은 부가적인 why 연결.

## 트리

서비스 기능 5개를 씨앗으로 두고 "왜 중요한가"를 올라간 트리. 뿌리는 "편안한 마음"이며, "뷰티 지속가능성"은 버짓 관리에서 점선으로 이어지는 별도 뿌리.

```
A. 편안한 마음                                              [why, 뿌리]
├─ B. 늙는 걱정 내려놓고 일/일상에 매진                      [why]
│  ├─ C. 바쁜 일상을 사느라 나만 속수무책 늙을지도 모른다는 불안감 방어 [why]
│  │  ├─ D. 노화에 대한 통제감                               [why]
│  │  │  ├─ E. 시술 효과 확신                                [why]
│  │  │  │  └─ F. 사진 기반 시술 효과 추적                   [씨앗]
│  │  │  ├─ G. 사진 기반 시술 주기 제안(추천)                [씨앗]
│  │  │  ├─ H. 1~3년 스킨케어 로드맵 디자인                  [씨앗]
│  │  │  └─ I. 마일스톤 연계 연간 버짓 관리                  [씨앗]  (점선) → N. 뷰티 지속가능성
│  │  ├─ J. 디톡스 (유해한 것을 끊는다)                      [how]   (점선)
│  │  └─ K. 자기위안                                        [why]   (점선)
│  │     └─ L. Peer 의 시술 통계 리포트 제공                 [씨앗]  (점선) → M. 체념
│  └─ M. 체념 / 늙음을 받아들인다                            [how]   (점선)
├─ O. 명상                                                  [how]   (점선)
├─ P. 운동                                                  [how]   (점선)
└─ Q. 상담                                                  [how]   (점선)

N. 뷰티 지속가능성                                          [why, 별도 뿌리]
└─ I. 마일스톤 연계 연간 버짓 관리                           [씨앗]  (점선)
```

## 노드 요약

- 씨앗(기능) 5: 사진 기반 시술 효과 추적, 사진 기반 시술 주기 제안(추천), 1~3년 스킨케어 로드맵 디자인, Peer 의 시술 통계 리포트 제공, 마일스톤 연계 연간 버짓 관리
- why 7: 편안한 마음, 늙는 걱정 내려놓고 일/일상에 매진, 바쁜 일상을 사느라 나만 속수무책 늙을지도 모른다는 불안감 방어, 노화에 대한 통제감, 시술 효과 확신, 자기위안, 뷰티 지속가능성
- how(아직 하지 않는 일) 5: 명상, 운동, 상담, 체념 / 늙음을 받아들인다, 디톡스 (유해한 것을 끊는다)
