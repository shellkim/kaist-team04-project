# 오늘 할 일 (Skin Scheduler P0)

현은혜 개인 프로토타입. 시술을 하나 넣으면 오늘 할 일이 구체 문장으로 나온다.

달력, 푸시, 점수, 전후 사진은 없다.

## Run

```bash
cd prototypes/eunhyehyun
npm install
npm run dev
```

브라우저에서 표시된 주소(보통 `http://localhost:5173`)를 연다.
기록은 이 브라우저의 localStorage (`eunhyehyun.skin-checklist`)에만 남는다.

## Test

```bash
npm test
npm run build
```
