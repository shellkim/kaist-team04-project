# Year Pacemaker — 내 1년을 설계해주는 언니 (P0 프로토타입)

Author: solbi kim (김솔비)
Date: 2026-10-29
Spec: `docs/specs/solbikim-year_pacemaker.md`

## 실행

의존성 없음. `index.html`을 브라우저에서 열면 됩니다.

```
open prototypes/solbikim/index.html
```

## 범위

- 첫날 플로우: 사진 고르기 → 강점 3개 → 지킬 것 → 분위기 어휘 → 두 장의 미래 → 예산 → 1년 루틴 → 결제(목업)
- 시계: 생리주기 위에 루틴 일정을 올린 이번 달 달력, 언니의 타이밍 한 줄, 기록과 연간 예산 게이지
- 분기 재분석: 설명 카드 한 장 (P2)

## 동작 원칙

- 사진은 브라우저 안에서만 읽습니다(파일 선택 → object URL). 어디로도 전송되지 않습니다.
- 강점은 시연용 고정값 3개이며, "다르게 보는데?"로 직접 고를 수 있습니다.
- 루틴은 규칙 기반입니다. 지킬 것에 닿는 시술만 후보로 두고 연간 예산을 넘지 않을 때까지 채웁니다. 비용·주기는 일반적으로 알려진 범위의 예시입니다.
- 선택과 기록은 localStorage에만 저장됩니다. 하단 "초기화"로 지웁니다.

## 손으로 하는 검사

1. 예산을 100 / 300 / 1000만원으로 바꿔 루틴 합계가 예산을 넘지 않는지 확인
2. 마지막 생리일을 오늘, 주기 28일로 넣고 황체기 띠에 시술 점이 없는지 확인
3. 언니 문장에 병원 이름이나 겁주는 표현이 없는지 읽기
